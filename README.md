# 🐙 Knowledge Base

**Public knowledge, frameworks, and systems for building AI automation that scales.**

## Core Frameworks

### The 3-Layer Architecture

**Layer 1: Core Data Architecture**
- Central knowledge graph
- Obsidian + NotebookLM + GitHub + Vector DB
- Single source of truth that feeds everything

**Layer 2: Automation Engine**
- Composio MCP (500+ app integrations)
- Claude Code plugins
- Relevance AI agents
- Make/Zapier workflows

**Layer 3: Content Factory**
- Input → Processing → Production → Distribution → Analytics
- Template-based content multiplication
- Feedback loops for continuous improvement

### The North Star Question

**"Will this scale to 1000x without breaking or requiring 1000x more effort?"**

Apply this to every decision:
- ✅ Template-based = scales
- ✅ Automated = scales
- ✅ Self-service = scales
- ❌ Manual = doesn't scale
- ❌ Custom every time = doesn't scale
- ❌ High-touch = doesn't scale

### ADHD Accommodations in AI Work

**Visual Systems:**
- Emoji-based scanning for fast pattern recognition
- Color coding for priority/status
- Short paragraphs, clear sections

**Decision Reduction:**
- Don't offer options (decision fatigue)
- One clear next step
- Execute first, refine later

**Energy Management:**
- Build in fresh-brain morning hours
- Admin/documentation in afternoon
- Creative/strategic in evening (when brain is tired but ideas flow)

### Building in Public Framework

**Why build in public:**
1. Accountability (can't ghost the internet)
2. Documentation as you go (not after)
3. Community building before selling
4. Proof of work (show, don't tell)

**What to share:**
- ✅ Session docs (real work, real time)
- ✅ Wins and mistakes
- ✅ Tools and systems
- ✅ Revenue and metrics (later)
- ❌ Client details
- ❌ Sensitive business info
